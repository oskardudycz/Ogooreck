### Step-1. A non-finite double crashes decoding

Quote: `case 33: value = input.ReadDouble();` turned into a `JsonNode`, then `value.ToString()`
Consequence: `JsonNode` writes JSON, which has no `NaN` or `Infinity`, so a span with a `NaN` tag throws `ArgumentException` (reproduced with a script) and the whole export is lost. Before the change it came back as `"NaN"`.
Belongs to: implementation
Resolution: fixed. Non-finite doubles become the strings `"NaN"`, `"Infinity"`, `"-Infinity"`, as before for scalars and as OpenTelemetry's non-OTLP mapping writes them; the fixture sets `own.unknown = double.NaN` and 1.1 asserts `"NaN"`.

### Step-2. Null array items behind an uncovered branch

Quote: `items.Any(item => item is not null && Matches(regex, item))`
Consequence: an array item of a type `ValueOf` skips (bytes, kvlist) became a `null` item, and the `null` branch had no test, so the coverage gate would fail.
Belongs to: implementation
Resolution: fixed. Unsupported items are dropped (`OfType<JsonNode>()`), the same way an unsupported scalar attribute is dropped today.

### Step-3. Fixture tag the step doesn't list

Quote: `.SetTag("own.attempts", new[] { 1, 2 })`
Consequence: none wrong; the step's tests only use a string array, so nothing guarded the decision that items keep their type (`../qa.md` 116). 1.1 and the import test assert `[1,2]`.
Belongs to: implementation
Resolution: fixed (kept as a deviation).
