### Step-9. Cancelling the Then token does not stop a step while it buffers the response body

Quote: TestStep.cs:20-22 `var response = await send(client, context); await response.Content.LoadIntoBufferAsync(); return response;`. `TestStep.Run(HttpClient, StepContext)` takes no token; WhenApiSpecificationBuilder.cs:50 only calls `ct.ThrowIfCancellationRequested()` before each step. Spec, Scenario flow (spec.md:357): "Cancelling `ct` stops steps, catch-up and waiting, and `Then` ends with `OperationCanceledException`." Spec, Steps: "Every response body is read into memory." The plan's extra test `then_withACancelledToken_endsWithOperationCanceledException` cancels only before `Then` starts.
Consequence: A step that sends with `HttpCompletionOption.ResponseHeadersRead` to a streaming endpoint (SSE, a long download) is buffered by Ogooreck without the token. If `ct` is cancelled while the body is read, `Then` keeps reading until the stream ends, or forever, and never throws `OperationCanceledException`. `LoadIntoBufferAsync(CancellationToken)` exists on net10. No test cancels while a step runs.
Belongs to: implementation (spec.md:357 decides it)
Resolution: implementation: sent back to the step 1 implementer.

Spec, Package and release (spec.md:272-273): "These are removed: The old builders, `GivenApiSpecificationBuilder` and `WhenApiSpecificationBuilder`." Consequence: The removal list feeds MIGRATION.md (qa 42) and the README rewrite in step 13.
